## What we are building
riverwaterlevels.com: a Lakebrief-style, ad-supported US river gauge site. One page set per USGS stream gauge (Dashboard, Water, Forecast), river hubs, state pages, trust pages. API data from US government sources only, no composed prose or verdicts, a Source line on every block, a block shows only when its source terms are cleared. Plan: 9,099 gauges in the inventory, about 25 new pages per day after the owner lifts the noindex hold. Rivers and creeks (not tidal). Domain registered 2026-10-16, served by a Cloudflare Worker with static assets.

## Gotchas
USGS rate-limits bursts (429): use `collect.py --fast`, `--nws-only`, `--extras-only --keys=...`, never several full collects an hour. The SNOTEL API ignores its network filter: filter `:SNTL` in code. RFC rain products have different valid-through times. Table head and body must stay one table (CSS display:table). Read screenshots: render_test does not catch visual bugs. Never write backslash code through a shell heredoc (use Write/Edit). A syntax error in lib/render.py stops the build; nothing is published.
